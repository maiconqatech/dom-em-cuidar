# Dom em Cuidar — Landing page

Landing page estática (HTML + CSS, sem build) da Dom em Cuidar Ltda, home care com sede em Santo Estevão e atendimento em todo o Brasil.

Publicada no GitHub Pages: https://maiconqatech.github.io/dom-em-cuidar/

- `index.html` — página, SEO e dados estruturados (LocalBusiness, serviços e FAQ em JSON-LD)
- `robots.txt` — libera buscadores e assistentes de IA
- `sitemap.xml` — mapa do site para o Google Search Console
- `llms.txt` — resumo da empresa para IAs

Ao usar domínio próprio, troque `https://maiconqatech.github.io/dom-em-cuidar/` em todos esses arquivos.
